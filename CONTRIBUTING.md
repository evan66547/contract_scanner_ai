# Contributing

Thanks for your interest in **Contract Scanner AI**.

## How to contribute

- Prefer small PRs for docs, OCR engine notes, or admin UX fixes
- Run `make live-check` when touching OCR/runtime paths
- Do not commit local config, target lists, or generated scan data

## Pull requests

1. Fork (or branch) from `main`
2. Keep changes focused (docs, fixes, or one feature)
3. Update README / docs if behavior or setup changes
4. Open a PR with a short summary of *why*

## Code of conduct

Be respectful. This project is maintained by a small team; clear, kind feedback helps most.
